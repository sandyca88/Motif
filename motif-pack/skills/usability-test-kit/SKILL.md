# Usability Test Kit

Five well-chosen participants doing realistic tasks will reveal most major usability problems in a flow. This kit makes each step fast and rigorous.

## Mode A: Plan the test

1. **Research plan** (one page): objective, the decisions this test will inform, research questions (3–5), method (moderated remote by default; unmoderated for quick preference/findability checks), participants (5–8 per segment), timeline, success metrics per task (completion, time on task, errors, confidence rating 1–7).
2. **Screener**: 6–10 questions with disqualifying answers marked, avoiding leading questions; include one articulation question. Provide a recruiting message for email/LinkedIn.
3. **Test script**:
   - Intro (consent, recording, "we're testing the design, not you", think-aloud practice).
   - Warm-up questions (2–3) about their current behavior.
   - **Tasks** (4–6): scenario-based, goal-oriented, no UI words from the interface ("You want to pay your rent before Friday…", not "Click Payments"). Each task gets: scenario, success criteria, follow-up probes, and a post-task question (SEQ: "How easy or difficult was this?" 1–7).
   - Wrap-up: overall impressions, SUS or UMUX-Lite questionnaire, closing.
4. **Note-taking template**: a table per participant with timestamp, task, observation, quote, severity.

## Mode B: Synthesize results

Given notes, transcripts or recordings summaries:

1. Extract atomic observations (one behavior or quote per line, tagged with participant + task).
2. Cluster into themes (affinity mapping); name each theme as an insight sentence.
3. Rate each issue with severity: **Critical** (prevents completion), **Serious** (major delay/frustration), **Minor** (cosmetic/annoyance). Record frequency (e.g. 4/6 participants).
4. Task metrics table: completion rate, average time, SEQ, notable errors.
5. Recommendations: for each top issue, a design change, owner, effort (S/M/L).

## Readout format

- One-slide summary: 3 top findings, overall task success, the recommendation you most want approved.
- Findings: insight → evidence (quotes + frequency) → recommendation.
- "What worked well" section (keeps credibility, protects good decisions).
- Appendix: participants table (anonymized), full task metrics, method.

Offer to output the readout as a slide deck, a document or a Miro/FigJam-ready list of sticky notes.

## Rules

- Never invent quotes or data. Clearly separate observations from interpretations.
- Anonymize participants (P1, P2…). Remove personal data from outputs.
- Caution when generalizing from small samples: report counts, not percentages, when n < 10.
